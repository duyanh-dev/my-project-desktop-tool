✨ SCSS Compiler Engine

Hướng dẫn biên dịch mã nguồn SCSS sang CSS tiêu chuẩn với công nghệ Autoprefixer tích hợp.

Quản lý Dự án (Project)

Trước khi bắt đầu, hãy nhấn vào nút (+) ở bảng Projects bên trái để tạo một dự án mới. Việc này giúp bạn lưu trữ cấu hình folder riêng biệt cho từng website khác nhau.

Chọn Thư mục Nguồn (Source SCSS)

Nhấn 📂 Select SCSS Directory. Hệ thống sẽ theo dõi (Watch) toàn bộ thay đổi bên trong thư mục này. Ngay khi bạn nhấn Ctrl + S trong trình soạn thảo, Engine sẽ tự động làm việc.

Cấu hình Chế độ Xuất (Output Mode)

Bạn có hai lựa chọn quan trọng tại thẻ Main Controls:

  • At Place: File .css sẽ được tạo ngay bên cạnh file .scss tương ứng.
  • Custom Path: Bạn có thể chọn một thư mục dist/css riêng biệt để giữ cấu hình dự án gọn gàng.

Cấu trúc dự án nhiều file (Advanced)

Để quản lý hiệu quả, hãy sử dụng kỹ thuật Sass Partials:

  • File có dấu gạch dưới (_filename.scss): Engine sẽ chỉ theo dõi để biên dịch vào file chính, không xuất ra file CSS riêng lẻ (giúp gọn thư mục).
  • File chính (main.scss): Dùng lệnh @use 'folder/filename'; để gộp các file nhỏ.
  • Recursive Watch: Engine tự động theo dõi tất cả thư mục con, bạn không cần chọn lại folder khi thêm file mới.

Theo dõi Live Activity

Cửa sổ Terminal phía dưới sẽ hiển thị trạng thái biên dịch theo thời gian thực. Nếu có lỗi cú pháp (Sass Error), thông báo sẽ hiện đỏ kèm theo dòng bị lỗi để bạn sửa chữa ngay lập tức.

Tối ưu hóa (Autoprefixer & HUD)

Đừng quên vào tab Settings để bật Autoprefixer (tự động thêm prefix cho IE, Chrome, Safari) và Browser Error HUD để xem thông báo lỗi ngay trên trình duyệt mà không cần quay lại App.
